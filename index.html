Como vender para restaurantes

Uma solução simples para uma dor que todo restaurante entende.

O restaurante imprime um QR Code na recepção. O cliente entra na fila pelo celular. A equipe acompanha mesas disponíveis, horários de fila e chamadas pelo painel administrativo.

1. Você configura nome, capa, logo e horários 2. Restaurante coloca o QR Code na entrada 3. Cliente entra, informa nome completo e grupo 4. Equipe chama a mesa certa quando houver disponibilidade
