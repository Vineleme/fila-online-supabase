FAQ

Perguntas frequentes sobre fila digital para restaurantes.

O cliente precisa baixar aplicativo?

Não. Ele acessa a fila por QR Code ou link, informa os dados e acompanha a própria posição pelo navegador.

O restaurante consegue controlar mesas?

Sim. O painel permite configurar mesas por tamanho de grupo, acompanhar disponibilidade e chamar o próximo cliente compatível.

Funciona no celular?

Sim. A experiência foi desenhada para desktop, tablet e celular, tanto para cliente quanto para equipe.

Posso usar a marca do restaurante?

Sim. O sistema aceita nome, logo, capa e cardápio em PDF para a fila parecer uma solução própria do restaurante.
